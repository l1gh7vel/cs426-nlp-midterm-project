# cs426-nlp-midterm-project
Ayub, Elizabeth, and Ali's midterm project of replicating an experiment from the paper: BERTs of a feather do not generalize together: Large variability in generalization across models with similar test set performance.

The specific experiment replicated is the out-of-distribution generalization. 

Everything is in the following google drive link (https://drive.google.com/drive/folders/1KgoaJobD4D6i9s4Bok4SfnnQ4TsbqP0e?usp=sharing).

# Google Drive Folder Description

This Google Drive structure reflects a project workspace for a shared midterm research project. Below is a brief overview of the folder contents:

## 1. Results Folder
- Contains multiple CSV files (`midterm_bert_23.csv`, `midterm_bert_24.csv`, etc.) indicating different runs or versions of a BERT model used in the research.
- A `results.ipynb` notebook file, where the analysis of results from these CSV files is performed.

## 2. Figures Folder
- Includes two PNG files: `subcases_accuracy_plot.png` and `heuristic_accuracy_plot.png`. These are visualizations showing model accuracy across different cases or heuristics, generated from the results analysis.

## 3. Datasets Folder
- Contains the datasets used in the project:
  - `multi_nli_train.tsv` – MNLI dataset for training the model.
  - `hans_data.tsv` – HANS dataset used for evaluation.

## 4. Config Folder
- Holds configuration files (`train_config_23.yaml` and `eval_config_23.yaml`). These files define the settings and parameters for training and evaluating the models.
